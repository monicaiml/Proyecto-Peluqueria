# 💇 Proyecto Peluquería

## 📌 Descripción del proyecto

Proyecto académico desarrollado en equipo por Marc Bonet e Isabel Martínez dentro del módulo de Proyecto Intermodular.

El objetivo es diseñar y desarrollar una aplicación web para gestionar las citas de una peluquería, facilitando tanto las reservas de los clientes como la organización de la agenda del personal.

## 🎯 Objetivos

- Permitir a los clientes consultar los servicios disponibles y gestionar sus citas.
- Facilitar al personal la organización de las reservas y los horarios.
- Reducir errores, olvidos y solapamientos en la gestión de citas.
- Desarrollar una aplicación web clara, intuitiva y adaptable a distintos dispositivos.

## ⚙️ Tecnologías previstas

Las tecnologías que se están valorando para el desarrollo del proyecto son:

- **Java:** desarrollo de la lógica de la aplicación.
- **PostgreSQL:** almacenamiento y gestión de los datos.
- **HTML y CSS:** estructura y diseño de la interfaz web.
- **JavaScript:** interactividad y validaciones en la parte cliente.
- **Git y GitHub:** control de versiones y colaboración entre los integrantes del equipo.

Inicialmente se plantea desarrollar el proyecto sin framework, aunque se podrá valorar la incorporación de Spring Boot si las necesidades lo requieren.
